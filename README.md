# AD-SMART-Sample-Size
Code to generate estimates for sample size for the AD-SMART Trial. 

# File Description
- `slopepoweri.ado` and `slopepoweri.sthlp` = Functions to estimate power for difference in slopes (user amended to change STREC)
- `Covariance and Error Variance Parameters.do` = Analysis of CPAD Data to estimate *ADAS-COG* Variance/Covariance parameters for Slope Power Calculation
- `TengetalAIDLQCovariancematrix.pdf` = Reference Paper to estimate *A-IADL-Q* Variance/Covariance parameters for Slope Power Calculation
- `Calculate Timing of Each Stage Sample Size.R` = Recruitment Model to estimate when required sample size achieved for each stage
- `Calculate Stage Power.do` = Calculate Power Using staggered recruitment estimates
- `Calculate Overall (actual) Power.R` = Estimate the Overall (actual) Power
